# 南航上海路小站小程序项目状态

## 项目定位

本项目是仅服务南昌航空大学上海路校区的微信原生小程序。

核心定位：

* 饭点帮拿：高频入口
* 校园墙：失物招领、新生提问、校园动态
* 集市与求购墙：闲置交易和需求匹配
* 服务榜：校区生活服务与后续商业化入口
* 我的：个人任务和发布管理

## 技术约束

* 微信原生小程序
* JavaScript / WXML / WXSS
* 不使用云开发
* 不使用 npm
* 不使用 TypeScript
* 不使用第三方 UI 库
* 本地接口地址从 utils/config.js 读取
* 当前本地后端地址为 http://127.0.0.1:8080
