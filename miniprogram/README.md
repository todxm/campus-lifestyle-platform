# 南航上海路小站 · 微信小程序

面向南昌航空大学上海路校区的校园生活项目，使用微信原生小程序与独立 Spring Boot 后端。当前功能版本为 **V0.7**。

当前目标是完成现有功能收尾、整理 GitHub 文档并支持本地演示；暂不以正式上线或新增大型功能为目标。已完成一轮微信开发者工具体验检查和关键流程自动回归，但本仓库不将此声明为全面兼容性或生产验收。

## 功能范围

| 模块 | 当前实现 |
| --- | --- |
| 饭点帮拿 | 列表、分类筛选、发布、详情、接单、完成、取消、我的帮拿 |
| 校园墙 | 列表、失物招领/新生提问/校园动态筛选、发布、详情 |
| 集市与求购墙 | 出售/求购切换；求购列表、筛选、发布、详情、标记已找到、关闭、我的求购 |
| 服务榜 | 列表、分类筛选、详情、联系方式展示、联系点击统计 |
| 首页与我的 | 核心模块入口、我的帮拿、我的求购、服务榜入口 |

功能边界：

- 集市“正在出售”使用静态示例，尚未接入后端商品交易完整流程。
- “我的发布”“我的失物招领”“联系平台”“反馈建议”目前为占位入口。
- 未接入微信登录、openid 或可靠的用户身份认证；“我的”相关列表使用本地 `userContact`，不等同于服务端权限控制。
- 小程序尚未接入图片上传；后端已有的商品/服务图片上传接口不代表小程序已完成上传流程。
- 服务榜主要用于示例展示，不代表真实商家入驻、认证或运营成果。
- 未实现支付、在线聊天、评论和审核后台。

## 技术与仓库

- 微信原生小程序：JavaScript、WXML、WXSS。
- 不使用云开发、npm、TypeScript 或第三方 UI 库。
- 接口根地址统一由 [utils/config.js](utils/config.js) 提供。
- 配套后端：[campus-lifestyle-platform](https://github.com/todxm/campus-lifestyle-platform)，使用 Java 17、Spring Boot、MyBatis、MySQL。
- 后端仓库的 `frontend/` 为早期网页端，与本小程序是不同客户端，功能范围并不完全相同。

## 本地运行

### 1. 准备后端

先按配套后端 README 准备 JDK、MySQL、数据库表和本地连接配置，再启动后端。后端已提供 `database/schema.sql`、`database/demo-data.sql` 和空库复现说明，请按后端 README 在独立演示库中初始化。

在开发者工具所在电脑确认以下请求可访问：

```text
GET http://127.0.0.1:8080/help-tasks
GET http://127.0.0.1:8080/wall-posts
GET http://127.0.0.1:8080/wanted-items
GET http://127.0.0.1:8080/service-items
```

HTTP 200 只说明请求成功，还需检查返回数据与实际页面行为。

### 2. 导入微信开发者工具

1. 安装并登录微信开发者工具。
2. 导入本仓库根目录，项目类型选择小程序；根目录包含 `app.json`。
3. 使用自己有权限的 AppID 或工具提供的测试能力。仓库中的 AppID 不代表其他开发者获得访问权限，不要提交个人 AppID 或私有配置改动。
4. 不需要安装 npm 依赖或执行“构建 npm”。
5. 当前配置使用本地 HTTP，`project.config.json` 中关闭了 URL 校验，仅用于本地调试。基础库目前配置为 `trial`，实际兼容性需在工具中确认。
6. 编译并打开首页，确认后端保持运行。

当前 `BASE_URL` 为 `http://127.0.0.1:8080`。此流程以本机模拟器为目标；真机上的 `127.0.0.1` 指向手机自身，不能直接照搬本地地址进行真机演示。

## 演示与验收

使用独立测试数据与非真实联系方式，按以下顺序检查：

1. 首页：模块入口、返回与底部导航。
2. 帮拿：列表、筛选、发布、详情、接单、完成；另用测试任务检查取消与我的帮拿。
3. 校园墙：分类、发布、详情、发布后返回刷新。
4. 求购墙：切换、筛选、发布、详情；分别验证已找到、关闭与我的求购。
5. 服务榜：列表、分类、详情、联系方式展示与联系点击统计。
6. 检查空状态、请求失败提示、乱码、布局溢出和控制台错误。

完整验收需要微信开发者工具中的人工确认。历史接口检查、语法检查不等于本次全流程验收通过。截图和验收结果待实际完成后补充，不使用示意图片冒充运行截图。

## 常见问题

| 现象 | 优先检查 |
| --- | --- |
| `ERR_CONNECTION_REFUSED` | 后端进程、8080 监听与本机 HTTP 请求 |
| 接口 404 / 500 | 请求路径 / 后端错误日志 |
| 列表为空 | 响应内容、筛选条件、字段映射 |
| WXML 编译错误 | 报错文件行号、标签、引号与表达式 |
| AppID、插件、证书或缓存异常 | 开发者工具项目配置、重新导入与缓存 |
